# Installation

Die App ist eine Web-App (PWA). Einmal online öffnen, dann als App hinzufügen – danach funktioniert sie auch ohne Internet.

**Adresse:** https://ELZET17.github.io/assessment-trainer/

## Mac (Safari, macOS Sonoma oder neuer)

1. Die Adresse in **Safari** öffnen und kurz warten, bis die Startseite geladen ist.
2. Menü **Ablage → Zum Dock hinzufügen …** wählen (oder in der Symbolleiste auf das Teilen-Symbol klicken → **Zum Dock hinzufügen**).
3. Namen bestätigen und auf **Hinzufügen** klicken.

Die App erscheint im Dock und unter Programme und startet in einem eigenen Fenster.

## iPhone / iPad (Safari)

1. Die Adresse in **Safari** öffnen.
2. Auf das **Teilen-Symbol** (Quadrat mit Pfeil) tippen.
3. **Zum Home-Bildschirm** wählen und auf **Hinzufügen** tippen.

Die App startet dann im Vollbild ohne Browserleiste.

## Offline nutzen

Nach dem ersten Öffnen ist alles auf dem Gerät gespeichert. Danach funktionieren Training, Drill, Simulationen, Statistik und Akademie auch im Flugmodus. Updates werden beim nächsten Öffnen mit Internetverbindung automatisch geladen.

## Deine Daten

- Alle Ergebnisse liegen nur auf dem jeweiligen Gerät (im Browser-Speicher der App). Es gibt kein Konto und keinen Server.
- Mac und iPhone haben getrennte Daten. Übertragen: **Einstellungen → Exportieren (JSON)** auf dem einen Gerät, die Datei übertragen (z. B. per AirDrop) und auf dem anderen **Einstellungen → Importieren …** wählen. Beim Import werden Versuche zusammengeführt, nichts doppelt gezählt.
- Wichtig auf dem iPhone: Löschst du die App vom Home-Bildschirm oder die Website-Daten in Safari, sind auch die Ergebnisse weg. Exportiere daher ab und zu eine Sicherung.

## Lokal starten (für Entwickler)

```bash
npm install
npm run dev
```
